# Velocity App

Measure barbell velocity, power and range of motion with only a phone camera.

The project is in its first phase: a Python prototype that analyzes recorded videos, so the
measurement can be checked against a GymAware linear position transducer before the iPhone app
is built. See [prototype/README.md](prototype/README.md).

| Phase | What | Status |
| --- | --- | --- |
| 1 | Prototype analysis on recorded videos, validated against GymAware | In progress |
| 2 | iPhone app (Swift), analysis right after each set, history | Not started |
| 3 | Live in-set feedback and fatigue alerts | Not started |
| 4 | Load-velocity profiles, estimated 1RM, readiness | Not started |
| 5 | Programming integration | Not started |
